# 🤖 從 LLM API 到 AI Agent 的演進指南

> **核心概念比喻：**  
> 想像你要開一間餐廳，**LLM API** 就像是「把一個聰明的廚師關在沒有窗戶的房間裡」，他只會回答問題；而 **AI Agent（AI 代理人）**，則是「幫這位廚師裝上電話、給他食譜筆記本，並讓他自己決定下一步該做什麼」，變成能獨立完成任務的員工。

從零開始建構出一個 AI Agent，其實只需要把四個核心積木一塊塊疊上去：

---

## 🧱 建構 AI Agent 的四個核心階段

### 1. 純粹的 LLM API（大腦）
* **定位：** 只會「一問一答」的知識庫。
* **運作方式：** 這是一切的起點。當你透過程式呼叫 LLM API（例如 OpenAI、Gemini 或 Claude 的介面），你給它一段文字，它就根據訓練過的知識吐出一段文字。
* **限制：** 它沒有手腳，看不到今天的即時新聞、查不到你的行事曆，而且每次對話結束就「失憶」。

### 2. 加上「記憶」與「人設」（System Prompt）
* **定位：** 讓它變成懂規矩的聊天機器人（Chatbot）。
* **運作方式：** 為了不讓它每次都忘記剛剛說過的話，程式會在每次發送新問題時，把**過去的對話紀錄**打包一起傳給 API。同時，我們會在最前面塞入一段「系統指令（System Prompt）」，規定它的角色與規矩（例如：「你是一位親切的旅遊規劃師」）。
* **進化結果：** 這就是你平常使用的 ChatGPT 或一般客服聊天機器人，能順暢聊天，但依然只能「動口不動手」。

### 3. 接上「工具」（Function Calling / MCP）
* **定位：** 幫大腦裝上手腳。
* **運作方式：** 這是變成 Agent 最關鍵的一步。我們寫好幾個小程式（稱為 Tool，例如「查詢天氣 API」、「搜尋網頁」、「寄出 Email」），並用說明書告訴 LLM 這些工具怎麼用。
* **實際流程：**
  1. 你問：「台北現在會下雨嗎？」
  2. LLM 知道自己沒有即時資訊，於是它**不直接回答你**，而是吐出一張指令紙條：「請幫我執行 `查詢天氣(地點="台北")`」。
  3. 你的程式看到紙條後，去執行查詢並把結果丟回給 LLM。
  4. LLM 再將結果整理成自然語言回答你。

### 4. 啟動「思考與行動迴圈」（Agent Loop）
* **定位：** 真正能自主完成複雜任務的 AI Agent。
* **運作方式：** 如果任務很複雜（例如：「幫我查明天台北天氣，如果會下雨，就寫信通知明天的客戶改期」），做一次動作是不夠的。我們會用一個 `while` 迴圈把整個流程包起來，讓 AI 進入 **「思考 → 行動 → 觀察結果」** 的循環（業界常稱為 ReAct 模式）：
  1. **思考（Thought）：** 任務還沒完成，我需要先查天氣。
  2. **行動（Action）：** 呼叫天氣工具。
  3. **觀察（Observation）：** 發現明天降雨機率 $80\%$。
  4. **再思考（Thought）：** 既然會下雨，下一步該呼叫寄信工具了。
  5. **完成（Finish）：** 直到 LLM 判斷所有條件都達成，它才跳出迴圈，向你回報「已處理完畢」。

## 📊 一眼看懂三者的差別

| 階段         | 核心組成                      | 能力比喻             | 實際例子                                                                                                          |
| :----------- | :---------------------------- | :------------------- | :---------------------------------------------------------------------------------------------------------------- |
| **LLM API**  | 大腦（模型本體）              | 博學但失憶的顧問     | 你問：「寫一首關於貓的詩」，它寫完就結束。                                                                        |
| **Chatbot**  | 大腦 + 記憶 + 角色設定        | 記得上下文的客服人員 | 你可以接著說：「把剛剛那首詩改成英文」，它聽得懂。                                                                |
| **AI Agent** | 大腦 + 記憶 + 工具 + 自主迴圈 | 能獨立解決問題的助理 | 你說：「幫我找一家明天有空位、評價 $4.5$ 顆星以上的義大利餐廳並訂位」，它會自己搜尋、比對、操作訂位系統直到完成。 |

---

## 💡 零基礎小撇步

你不需要從頭自己寫那個複雜的迴圈。現在有很多現成的工具都已經把這個「迴圈骨架」做好了，你只要負責寫好指令（Prompt）並把工具插上去就行：
* **無程式碼視覺化平台（No-Code）：** `n8n`、`Dify`
* **程式開發框架（Code）：** `LangGraph`、`OpenAI Agents SDK`
