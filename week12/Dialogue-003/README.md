# 🎭 第二階段詳解：加上「記憶」與「人設」（System Prompt）

在第一階段，我們認識了「純粹的 LLM API」，但它有個致命缺點：**每次對話結束就失憶**，而且回答總是像個沒有感情的百科全書。

為了讓它變成一個能順暢聊天、懂規矩的 **Chatbot（聊天機器人）**，我們必須在程式裡幫它加上兩個關鍵設計：**「對話歷史（記憶）」**與**「系統指令（人設）」**。

---

## 1. 魔法揭密：API 其實根本不會「記憶」！

這可能是所有初學者最驚訝的真相：**LLM API 本身依然是失憶的！** 那為什麼我們在用 ChatGPT 或客服機器人時，它能記得我們剛才說過的話？

因為開發者在背後耍了一個「小魔術」——**每次發送新問題時，程式都會把「從頭到尾的聊天紀錄」重新打包，全部再寄給 API 一次！**

### 🍲 餐廳點餐的比喻（進階版）
* **沒有記憶時：** 你每次走進餐廳，都要重新點餐，廚師根本不認識你。
* **加上記憶後：** 服務生（你的應用程式）拿著一本**點餐筆記本**。每次你要加點，服務生就把「整本筆記本」遞進廚房給大廚看。大廚從第一頁看到最後一頁，瞬間了解前因後果，然後接著寫下新的回覆。

### 實際傳送給 API 的資料長這樣（對話陣列）：
在程式裡，這本筆記本是一個清單（List），裡面會標註每句話是誰說的（角色 Role）：

1. **`user`（使用者）：** 「你好，我叫小明，我喜歡吃蘋果。」
2. **`assistant`（AI 助手）：** 「你好小明！蘋果是很健康的水果喔。」
3. **`user`（使用者）：** 「我叫什麼名字？我喜歡吃什麼？」 *(👈 這才是你剛打的新問題，但前兩句也一起被送出去了！)*

> **💡 零基礎小知識：為什麼聊太久 AI 會變笨或變貴？**
> 因為每次都要把「整本筆記本」重傳一次，聊得越久，筆記本就越厚（Token 數量暴增）。不僅花費變高，當字數超過大腦的閱讀上限（稱為 **Context Window 上下文視窗**）時，最早的記憶就會被擠掉、遺忘！

---

## 2. 賦予靈魂：什麼是 System Prompt（系統指令）？

如果只給大腦記憶，它還是一個「什麼都聊、沒有立場」的普通人。如果我們想把它變成「專業的英文家教」或「脾氣暴躁的貓咪」，就需要用到 **System Prompt（系統提示詞）**。

在傳送給 API 的那本「點餐筆記本」中，我們會把 **System Prompt 永遠釘在第一頁的最上方**，它的權限最高，用來規定 AI 的行為準則。

### 🎭 三種常見的「角色（Role）」分工

| 角色標籤                   | 白話解釋                                                                       | 實際內容範例                                                                                   |
| :------------------------- | :----------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| **`system`（系統/導演）**  | 躲在幕後的導演，負責規定 AI 的個性、語氣、任務與禁忌。使用者通常看不到這段話。 | `"你是一位擁有 10 年經驗的台灣旅遊規劃師，講話親切、愛用 emoji，且絕對不推薦已經倒閉的店家。"` |
| **`user`（使用者）**       | 真正來問問題的人類。                                                           | `"我想去台南玩兩天一夜，有推薦的嗎？"`                                                         |
| **`assistant`（AI 助手）** | AI 自己過去說過的話（用來維持對話連貫性）。                                    | `"沒問題！台南超好玩的，第一天我推薦你從中西區開始..."`                                        |

### 為什麼 System Prompt 這麼重要？
沒有 System Prompt 的 AI 就像「剛入職的新人」，你問什麼它就隨便答；有了 System Prompt 的 AI 就像「受過嚴格訓練的員工」，它會**死守你設定的人設與規則**，不會輕易被使用者帶偏。

## 3. 第二階段的成果與依然存在的瓶頸

把「大腦（LLM API）」＋「筆記本（記憶）」＋「導演劇本（System Prompt）」組合起來，恭喜你！你已經親手做出了市面上 $80\%$ 的 **AI 聊天機器人（Chatbot）** 產品（例如：AI 心理諮商師、AI 英文口說練習器、企業內部知識問答機器人）。

### ⚠️ 但是，它依然還不是 AI Agent！為什麼？
因為到了這個階段，AI 依然被關在「沒有窗戶的房間裡」：
1. **它還是不知道外界的即時資訊：** 就算你設定它是「旅遊規劃師」，它也不知道「明天台南會不會下暴雨」或「高鐵票還有沒有位置」。
2. **它還是無法幫你執行動作：** 它能幫你排好完美的行程表，但沒辦法幫你「打開訂房網站下單」或「把行程寄到你的信箱」。
